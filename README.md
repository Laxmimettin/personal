
# Responsive Personal Portfolio Website

## Description
A professional responsive portfolio website built using HTML5,
CSS3, and JavaScript. It presents a developer's profile, skills,
projects, education, and contact information.

## Objectives
- Practise semantic HTML5 structure.
- Create responsive layouts with CSS Grid and Flexbox.
- Implement mobile navigation using JavaScript.
- Validate contact form inputs.
- Present technical skills and projects professionally.

## Features
- Home and About sections
- Technical Skills section
- Featured Projects section
- Education and Achievements section
- Contact form with input validation
- Responsive navigation menu
- Typing animation
- Responsive desktop, tablet, and mobile layouts

## Technologies
- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git and GitHub

personal-portfolio/

## How to Run
1. Open the project folder in VS Code.
2. Open index.html in a browser.
3. Alternatively, install Live Server in VS Code.
4. Right-click index.html and select Open with Live Server.

## Customisation
Replace the example profile information with your own details.
Add your GitHub repository links and update education information.

## Contact Form
The form currently validates data in the browser only.
Connect a backend or form service to receive actual messages.

## Conclusion
This project demonstrates the fundamentals of responsive web
design, semantic HTML, CSS layouts, navigation, and JavaScript
form validation.
